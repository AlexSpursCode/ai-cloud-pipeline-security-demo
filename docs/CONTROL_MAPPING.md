# Control mapping

The risk mapper correlates missing pipeline controls with three families of controls:

## OWASP LLM

- `LLM01`: prompt injection
- `LLM05`: supply chain vulnerabilities
- `LLM06`: sensitive information disclosure
- `LLM07`: insecure plugin and tool use
- `LLM08`: excessive agency

## Cloud security

- IAM least privilege
- asset inventory
- vulnerability management
- logging and monitoring
- continuous validation

## Supply chain

- credential hygiene
- SBOM and provenance
- dependency risk monitoring
- release security testing
- workflow hardening
